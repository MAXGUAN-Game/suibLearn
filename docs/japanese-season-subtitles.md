## 孤独的美食家

各集源视频实测 1920×1080 H.264、日语 EAC3，内封 3 条 SubRip：`jpn / Japan`、`chi / Simplified`、`chi / Traditional`。三轨分别直接提取到 `原始日文`、`简体中文`、`繁体中文`。

日中字幕来自不同断句，不能按行号或原始起止时间直接配对。按时间重叠关联不同语轨，合并同一台词段落，采用日文时间轴，再输出同起止时间的 `JP` 和 `CN` ASS 事件。中文画面文字和未匹配日文短句保留为单语条目，不凭空补译。

上传版清理了听障字幕中的括号说话人、音效、纯音乐，以及源轨将 ruby 拆行产生的重复读音。读音清理使用逐一检查的汉字／假名对，不能简单删除所有假名行，否则会删掉真实台词。原始提取轨保持不变。

源日文轨在片尾实地探访部分有缺漏，个别中文包含的内容没有完整日文对应。不能把这部分当作逐字双语对照；首集正文适合测试。

## 导入与验证约定

后端 `parse_subtitle_file()` 按相同起止时间匹配 `JP`／`CN` 样式。直接上传两行双语 SRT 会被当成单条原文，不能分别开关。所有 22 份 ASS 均经当前解析器重解析，检查条数、日中配对、有效时间范围和最长分组，并抽查两个首集的配对内容。

首集视频使用 NVENC H.264、原始分辨率、AAC 160kbps 双声道和 `+faststart`，显式排除字幕轨。源文件不变。视频与字幕通过 SFTP 流式传输，避免上传接口将整片读入内存；校验服务器容量及 SHA256 后，调用生产应用的 `create_video()`、`insert_subtitle_lines()` 和 `update_video_status()` 发布。设置 `source_language=ja`，复用同名合集并防止重复首集。

导入前创建 SQLite 在线一致性备份。验证范围包括生产解析器、API ready 状态、媒体 Range、浏览器解码、跳转、日语／日中／无字幕切换，以及真实 DeepSeek 句子解析。最终首集结果见对应本地 `上传测试结果.json`；线上链接与实际检查结果见开发交接追加记录。
